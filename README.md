# HAITO ADMIN

HAITOアプリ用の配当マスターを管理する**非公開**リポジトリです。

## 現在の状態
- GitHub上に初期ファイルを設置済み
- 配当マスター形式: `schemaVersion: 1`
- CSVを手元の HAITO ADMIN v0.1 に取り込んで審査し、承認済みのみJSON出力できます
- GitHub上の公開配信URL・ログイン付き管理画面・自動公開は**未設定**です

## 安全な更新フロー
1. 公式IRを調査し、対象年度・開示日・出典URLを記録
2. 管理画面で配当額と利用許諾条件を確認
3. 承認した銘柄だけを `data/dividend_master.json` に反映
4. GitHub ActionsがJSON構造を検証
5. 将来、商用利用可能なHTTPS配信先へ公開（未実装）

**注意:** リポジトリを公開しないでください。公開用JSONにも配当データの再配信に必要な権利確認が必要です。実データは未登録です。
CSV一括取り込み機能のプレビュービルド確認用更新。
