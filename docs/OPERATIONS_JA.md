# HAITO ADMIN 運用ガイド

## 今できること
- 手元の HAITO ADMIN v0.1（index.html）で銘柄を登録し、CSV取り込みとJSON出力ができます
- このGitHubリポジトリは非公開のまま維持します
- data/dividend_master.json はアプリが読める形式です
- data/approvals.json は公開前の監査記録です。公開JSONの全銘柄に一致する承認がなければ検証が失敗します

## まだできないこと
- ブラウザ管理画面からGitHubへ直接保存すること
- 管理者ログイン、インターネット公開、iPhoneアプリへの自動配信
- 私が定期的にIR情報を勝手に更新すること

## 手順（将来の本番運用）
1. 公式IRで配当予想・決算期・開示日を確認
2. 再配信権利の根拠を確認
3. 管理者が承認（配当金額と出典のスナップショットを記録）
4. 配当マスターを更新
5. GitHub Actionsの検証が通った場合のみ配信対象にする

※ 利用条件の根拠URLが存在するだけで権利が確認できたことにはなりません。実際の条件を確認してください。

## 現時点で利用者がすること
何もしなくて大丈夫です。公開用のURLと管理者認証が整うまで、実データの配信は開始しません。
